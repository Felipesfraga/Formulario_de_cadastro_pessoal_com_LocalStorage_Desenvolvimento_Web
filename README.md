# 🌌 Cadastro Pessoal — Space Glassmorphism App

Um sistema de cadastro pessoal web com design moderno em estilo **Glassmorphism** (efeito de vidro translúcido) e tema espacial. Permite o cadastramento de informações de usuários com pré-visualização de foto de perfil em tempo real e persistência de dados no navegador através do `localStorage`.

## ✨ Funcionalidades

* 📸 **Upload com Preview:** Seleção de foto de perfil com visualização dinâmica instantânea usando a API `FileReader`.
* 💾 **Persistência de Dados:** Armazenamento dos cadastros no `localStorage` do navegador, garantindo que as informações não se percam ao atualizar a página.
* 🎨 **Design Moderno:** Interface responsiva com efeito de vidro fosco (*Glassmorphism*), sombras suaves e brilho neon nos campos e botões.
* 🗑️ **Gerenciamento de Cadastros:** Exibição dinâmica de todos os perfis cadastrados com opção individual de exclusão.
* 🧹 **Limpeza Automática:** Função para limpar o formulário e a foto pré-visualizada de forma simples.

## 📁 Estrutura do Projeto

```text
├── index.html     # Estrutura HTML da aplicação
├── style.css      # Estilização Glassmorphism e tema espacial
├── script.js      # Lógica do formulário, FileReader e localStorage
└── Space.jfif     # Imagem de fundo espacial
```

---

## 🚀 Como Executar o Projeto

1. **Clone ou baixe** este repositório para o seu computador.
2. Certifique-se de manter a imagem `Space.jfif` na mesma pasta dos arquivos do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Firefox, Edge, etc.).

---

## 💡 Aprendizados e Práticas Aplicadas

* Manipulação do DOM (Document Object Model) via JavaScript puro.
* Utilização da API `FileReader` para conversão de imagens locais em *Data URLs* (Base64).
* Armazenamento em memória local (`localStorage.setItem` / `getItem`).
* Propriedades avançadas do CSS como `backdrop-filter: blur()`, `flexbox` e transições suaves de efeito `hover`.
